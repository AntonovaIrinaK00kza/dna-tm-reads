# dna-tm-reads

Расчёт температуры плавления (Tm) ДНК по ридам секвенирования Illumina, сравнение алгоритмов поиска комплементарных ридов и веб-приложение на Streamlit.

Код сопровождает доклад на форуме «Телекоммуникационные и вычислительные системы» (МТУСИ, секция 7).

## Что умеет

- Потоково читает FASTQ (в том числе `.gz`), фильтрует риды по качеству Phred и по символам вне A, C, G, T.
- Считает Tm шестью методами: Wallace, Marmur–Doty, Chester–Marshak, Wetmur, формула (1.3) из доклада (Khandelwal-like) и nearest-neighbor (SantaLucia, 1998) с поправкой на Na⁺.
- Сравнивает четыре алгоритма поиска комплементарных ридов (обратный комплемент): полный перебор O(N²), хэширование O(N), сортировка O(N log N), приближённый поиск по k-мерам.
- Веб-приложение: гистограммы GC и Tm, таблица статистик (CSV), сравнение алгоритмов на загруженных данных.

## Установка

Нужен Python 3.10 или новее.

```
python -m venv .venv
.venv\Scripts\activate        # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Данные

В репозитории данных нет. Использованы открытые запуски NCBI SRA (Illumina, парные риды; брали первый файл пары и первые 100 000 ридов):

| Организм | Запуск |
|---|---|
| *Staphylococcus aureus* | SRR27019103 |
| *Escherichia coli* | SRR25145280 |
| *Pseudomonas aeruginosa* | SRR27376060 |

Скачать начало файла по ссылке из ENA:

```
python scripts/download_fastq.py "<ссылка на *_1.fastq.gz>" --reads 200000 --out data/saureus.fastq
```

## Запуск

```
python scripts/analyze.py --fastq data/saureus.fastq --name saureus --n-reads 100000
python scripts/plot_results.py --exclude Wallace --modes w20 w40 --out tm_vs_gc_clean.png
python scripts/benchmark_pairing.py --max-brute 20000 --max-seed 20000 --max-n 200000 --memory
streamlit run app.py
```

Условия расчёта по умолчанию: [Na⁺] = 50 мМ, концентрация цепей 50 нМ.

## Тесты

```
python -m pytest -q
```

17 тестов, включая сверку NN-реализации с Biopython (на 16–150 нт расхождение не больше 0,72 °C).

## Структура

```
app.py                  веб-приложение (Streamlit)
tmtools/                пакет: чтение FASTQ, методы Tm, алгоритмы поиска пар, общий анализ
scripts/                запуск расчёта, графики, бенчмарк, диагностика
tests/                  автоматические тесты
data/, results/         данные (не в репозитории) и результаты расчётов
```

## Основные результаты

- Средний GC ридов: 32,6 % (*S. aureus*), 51,4 % (*E. coli*), 66,2 % (*P. aeruginosa*); по референсным геномам 33; 51; 66,5 %.
- Все методы упорядочивают организмы одинаково (разница Tm 14–15 °C), но расходятся между собой на 11–24 °C.
- Хэширование быстрее полного перебора в 311 раз на 20 000 ридах (синтетические данные).

## Ограничения

Экспериментальных значений Tm для использованных образцов нет, поэтому сравниваются методы между собой, а не с экспериментом. Формулы для олигонуклеотидов на длинных ридах выходят за область применимости.
